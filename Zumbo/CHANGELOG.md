# Changelog

This changelog summarizes notable product milestones. Git history remains the detailed source of change ownership and chronology.

## 2026-08-18

- Improved adaptive project workflows: the standard five-column board now remains visible without a horizontal page canvas, work-item properties stay available at normal desktop widths, and mobile project-summary drill-through preserves its active filter.
- Added responsive and behavioral coverage for the affected desktop and mobile workflows.

## 2026-08-16

- Made recurrence scheduling idempotent across durable persistence paths, preventing duplicate scheduled work during retries and recovery.

## 2026-08-12

- Completed the modern Angular desktop and Ionic Angular mobile runtime transition.
- Added scoped PWA workers, runtime configuration, strict content-security-policy support and verified local asset manifests.
- Completed controller-based API presentation while preserving existing module contracts.

## 2026-08-11

- Completed desktop and mobile product surfaces for daily work, projects, planning, reporting, strategy, knowledge, administration and operations.
- Added data-backed permission metadata, organization and project roles, session invalidation and permission-aware navigation.
- Improved workflow-driven planning, roadmaps and responsive desktop/mobile behavior.

## 2026-08-10

- Added ranked board movement, WIP enforcement, optimistic concurrency recovery and realtime reconciliation.
- Separated My Work, Inbox and Notifications into focused daily-work experiences.
- Added the searchable project directory and grouped project navigation.

## 2026-07-30

- Reorganized backend production types into responsibility-specific files and feature-oriented slices.
- Established modular-monolith, vertical-slice and ports-and-adapters boundaries across business modules, API composition and persistence providers.
- Added architecture checks for module dependencies, top-level type ownership and source readability.

## 2026-07-22 to 2026-07-29

- Added project boards, work-item collaboration, configurable workflows, backlog and sprint planning.
- Added automation, intake, notifications, audit/privacy, reporting, dashboards and integrations.
- Added portfolios, goals, capacity planning and knowledge management.
- Added MongoDB and PostgreSQL provider contracts, Redis coordination, durable messaging and migration tooling.
- Expanded desktop and mobile accessibility, offline behavior, security controls and browser coverage.

## 2026-07-13 to 2026-07-21

- Established the .NET solution, shared building blocks, core business modules and API/gateway topology.
- Added organization, identity, team, project and work-management foundations.
- Added containerized local infrastructure and the initial desktop/mobile application foundations.
